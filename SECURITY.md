# Security Policy

## Supported Versions

This repository is for learning and experimentation in quantum-safe programming.
Security guarantees are not production-grade, but I welcome reports of issues.

## Reporting a Vulnerability

If you discover a security issue related to:

- Cryptographic usage (classical or post-quantum)
- Key management or secret handling
- Insecure configurations in example code

Please contact me at: [YOUR EMAIL HERE]

Include:

- A clear description of the issue
- Steps to reproduce (if applicable)
- Any suggested fix or reference

I will review reports as soon as possible and update the repository with fixes or notes.

## Scope

This repository focuses on:

- Quantum-safe cryptographic patterns
- Crypto-agile design
- Example code and educational materials

It does **not** manage real production secrets or live infrastructure.
Please do not submit real private keys, credentials, or sensitive data in issues or pull requests.
