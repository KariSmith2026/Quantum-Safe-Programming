# Quantum‑Safe Programming

This repository documents a structured progression of quantum‑safe cryptography experiments developed in a reproducible VirtualBox lab environment.  
Each lesson demonstrates practical implementations of NIST‑approved post‑quantum algorithms, hybrid cryptographic workflows, and secure communication protocols.

---

## 🚀 Project Summary

The **Quantum‑Safe Programming** project explores the intersection of classical and quantum‑resistant security.  
It includes verified implementations of:

- Hybrid ECDH + ML‑KEM key exchange  
- ML‑DSA file signing and verification  
- Secure channel persistence and rollback protection  
- Automated session key rotation  
- Multi‑message replay protection  
- Quantum‑Neural‑Network (QNN) training convergence milestones  

All modules are tested within a controlled Debian environment using VirtualBox snapshots for reproducibility.
